모기 스캐너 0.4 — 전체 실행 패키지

포함: 소스코드, 변환된 YOLito AI 모델, ONNX Runtime Web 실행 라이브러리, 라이선스.
AI 모델 재다운로드나 변환 없이 dist 폴더 그대로 실행할 수 있습니다.
원본 PyTorch 학습 체크포인트와 학습 데이터는 포함하지 않습니다.

바로 쓰기 (휴대폰 포함)
https://dangnani-pixel.github.io/mosquito-scanner/ 를 Safari 또는 Chrome에서 엽니다.
(GitHub 저장소 Settings → Pages → Source 를 "GitHub Actions"로 한 번 설정해야 주소가 열립니다.)

PC 실행 (Python 3 설치 필요)
1. 이 폴더에서 터미널을 열고 실행합니다.
   python -m http.server 8000 --bind 127.0.0.1 --directory dist
2. 브라우저에서 http://localhost:8000 을 엽니다.
3. 카메라 시작 → AI 정밀 촬영 또는 실시간 모기 AI 켜기.

휴대폰에서 카메라/마이크 권한을 쓰려면 HTTPS 주소가 필요합니다.
휴대폰에서 PC의 일반 HTTP IP 주소를 열거나 index.html 파일을 직접 여는 방식은 권장하지 않습니다.

모델은 기기 안에서 실행됩니다. 처음 접속할 때 약 60 MB를 받아 검증한 뒤 브라우저에 저장하고,
다음부터는 저장된 모델을 씁니다.
실시간 AI는 수초 간격 판정이며 붉은 상자는 연결된 움직임을 따라갑니다.
정확도는 실제 방과 아이폰에서 미검증입니다. 모기 확정 판정이 아닙니다.
README.md, LICENSE, dist/NOTICE.txt에 기술 설명과 출처가 있습니다.
